# Qualitätsszenarien – QuizMaster

| Q-Attribut             | Quelle               | Stimulus                                           | Artefakt                          | Umgebung                                   | Antwort                                                                                                       | Antwortmaß                                                                           |
| ---------------------- | -------------------- | -------------------------------------------------- | --------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **Verfügbarkeit**      | Benutzer             | Möchte ein Quiz starten                            | QuizMaster-Anwendung              | Normalbetrieb                              | Das System lädt das ausgewählte Quiz und stellt die erste Frage dar.                                          | Das Quiz ist innerhalb von 2 Sekunden startbereit.                                   |
| **Änderbarkeit**       | Entwickler           | Möchte ein bestehendes Quiz ändern                 | Fragenmodell und Quizlogik        | Entwicklungsumgebung                       | Das Quiz wird angepasst ohne eine Datei im System manuell beschreiben zu müssen                               | Das ändern von Quizzes funktioniert ohne Fehler und innerhalb von 3 minuten          |
| **Leistungsfähigkeit** | Benutzer             | Wechselt zur nächsten Quizfrage                    | Quizoberfläche und Quizlogik      | Normalbetrieb während eines laufenden Quiz | Das System verarbeitet die Eingabe und zeigt die nächste Frage an.                                            | Die nächste Frage wird innerhalb von 500 ms angezeigt.                               |
| **Benutzbarkeit**      | Erstmaliger Benutzer | Möchte ein Quiz starten und eine Frage beantworten | Grafische Benutzeroberfläche      | Normalbetrieb ohne vorherige Einführung    | Die Oberfläche führt verständlich durch den Quizablauf und visualisiert ausgewählte Antworten sowie Feedback. | Mindestens 90 % einer Testgruppe können ein Quiz ohne Hilfe erfolgreich durchführen. |
| **Zuverlässigkeit**    | Benutzer             | Öffnet eine beschädigte oder ungültige Quizdatei   | Quiz-Import und Datenverarbeitung | Normalbetrieb mit fehlerhafter Quizdatei   | Das System erkennt den Fehler, zeigt eine verständliche Fehlermeldung und bleibt bedienbar.                   | Kein Programmabsturz; die Anwendung bleibt in 100 % der getesteten Fälle bedienbar.  |
